# Found-AND-Lost
Campus Lost &amp; Found API is a FastAPI-based REST service for managing lost and found reports on a campus. It allows users to create, view, update, filter, and delete item reports using a SQLite database. The API includes validation for required fields and status/category filtering

TO ACCESS THE SWAGGER:

STEP 1: RUN (fastapi dev main.py)

STEP 2: CLICK ON THE LINK (http://127.0.0.1:8000/docs) USING [ clrt+right click]
